## 三、运行期发现并修复的问题

| # | 类型 | 问题 | 修复 |
|---|---|---|---|
| 1 | 部署 | `.dockerignore` 排除 `target/`、`*.jar`，镜像构建找不到 jar | 白名单 `!target/campus-format-server.jar` |
| 2 | 部署 | MySQL/Redis 端口映射与 Windows 保留端口冲突 | 移除宿主机映射，仅容器内互通 |
| 3 | 启动 | `SecurityConfig` 与 `RateLimitFilter` 循环依赖 | 拆分 `RedisConfig` |
| 4 | 启动 | Spring Boot 3 使用旧前缀 `spring.redis.*`，Redis 连 localhost | 改为 `spring.data.redis.*` |
| 5 | 契约 | `/formats` 未判断引擎健康，可选引擎缺失仍显示可用 | 可用性 = 支持 + `healthCheck()`，并缓存结果 |
| 6 | 稳定性 | 队列轮询异常直接抛出，Redis 抖动时刷栈 | 捕获异常并告警，调度器保持存活 |
| 7 | 环境 | Docker Hub 认证被 DNS 污染 | 配置镜像加速（DaoCloud / 1ms） |
| 8 | 环境 | Docker Desktop 的 WSL2 后端未就绪 | 启用 WSL2 后启动引擎 |
