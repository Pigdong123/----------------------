## 六、运行期发现并修复的问题

| # | 问题 | 影响 | 修复 |
|---|---|---|---|
| 1 | Docker Desktop 配置为 WSL2 后端，但 WSL 未安装 | 引擎无法启动 | 启用 WSL2 后启动 Docker Desktop |
| 2 | Docker Hub 认证域名被解析到异常 IP | 基础镜像拉取失败 | 配置镜像加速：DaoCloud / 1ms |
| 3 | 宿主机 6379 落在 Windows 保留端口段 6363–6462 | Redis 容器无法绑定端口 | 移除 MySQL/Redis 宿主机端口映射，仅容器内互通 |
| 4 | `.dockerignore` 排除了 `target/` 与 `*.jar` | 后端镜像构建找不到 jar | 白名单 `!target/campus-format-server.jar` |
| 5 | `SecurityConfig` 定义 Redis 模板又注入 `RateLimitFilter` | 启动期 bean 循环依赖，应用无法启动 | 拆分 `RedisConfig`，独立声明 Redis 模板 |
| 6 | Spring Boot 3 仍使用 `spring.redis.*` | Redis 实际连接 `localhost:6379` | 改为 `spring.data.redis.*` |
| 7 | `/formats` 只判断引擎是否支持，未判断健康状态 | 可选引擎缺失时仍显示“可用” | 可用性 = 支持 + `healthCheck()`，并缓存健康结果 |
| 8 | 队列轮询异常直接抛出 | Redis 抖动时定时任务刷栈 | 捕获异常并记录告警，保持调度器存活 |
