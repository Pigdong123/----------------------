## 二、执行前准备

1. 安装并启动 Docker Desktop（Windows）。
2. 准备环境变量：

   ```bash
   cd "program file/deploy"
   copy .env.example .env
   ```

3. 启动四服务：

   ```bash
   docker compose up -d --build
   ```

4. 等待 `campus-format-app` 健康（查看日志出现 `Started CampusConvertApplication`）：

   ```bash
   docker compose logs -f app
   ```

5. 确认前端可访问：<http://localhost>；接口文档：<http://localhost:8080/api/doc.html>。

## 五、常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 注册返回 1011 | 同 IP 1 分钟内注册超过 5 次 | 等待 1 分钟或换账号 |
| 登录返回 1011 | 同 IP 1 分钟内登录超过 10 次 | 等待 1 分钟 |
| 任务失败：引擎无法启动 | 容器缺少 ffmpeg/LibreOffice/ImageMagick | 重新构建 `server` 镜像 |
| 下载返回 1006 | 令牌已被使用或超过 10 分钟 | 重新获取任务详情获得新令牌 |
| 上传返回 1003 | 扩展名不在白名单 | 检查 `campus.file.allowed-extensions` |
